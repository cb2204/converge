# brain/ — user-generated inputs (the second brain's front door)

tidy.** Every entry: one line — what it is, where, why it matters. The
Converge grounding steps (Pass 0 Step 1, Pass 1 Step 1.5) read this file
first; anything indexed here is a question the grill never asks.

refs, decisions). `docs/` + `sketch/` + root `tasks/` are cvg-generated
(gate-contract paths — never store inputs there).

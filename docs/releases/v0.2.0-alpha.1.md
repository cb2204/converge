# Converge 0.2.0-alpha.1

Status: release candidate until hosted gates pass and the exact merge commit is tagged.

## What changed

- Added `cvg compose prepare`, `review`, `preview`, `materialize`, and `status`.
- Added `ConvergeCompositionReceipt/v1` with source, engine, review, lineage, TaskPlan, materialization, and task hashes.
- Made Task-Spec 3.8.0 an external required engine for the core lifecycle.
- Made Seamwise 0.2.0-alpha.1 an external optional engine required only by compose.
- Removed the embedded Task-Spec tree from the Converge package.
- Added one universal `ConvergeCLIResult/v1` envelope for all 57 forms, including help, version, and agent-context.
- Added a canonical CLI matrix, release Makefile, deterministic composed E2E, and explicit package allowlists.
- Preserved exactly eleven Converge-owned skills and all stable `bin/`, `skills/`, `apps/`, `contracts/`, and plugin roots.

## Migration from v0.1.0

Converge v0.1.0 bundled a Task-Spec implementation. That tag remains immutable
and is not representative of the 0.2 composed architecture.

1. Install Task-Spec 3.8.0 independently.
2. Remove any consumer-local Converge-projected `skills/task-spec` copy.
3. Reinstall Converge 0.2.0-alpha.1 so the coordinator, contracts, templates, and eleven skills are pinned together.
4. Install Seamwise 0.2.0-alpha.1 only when using `cvg compose`.
5. Replace any workflow that assumed Seamwise compilation wrote Task-Spec Markdown with `cvg compose preview` followed by `cvg compose materialize`.
6. Update JSON consumers to read `ConvergeCLIResult/v1`; under `--json`, agent-context is now at `data.agent_context`.

Existing Task-Spec lifecycle commands keep their public Converge forms and
delegate to the standalone engine.

## Alpha boundary

This release proves composed single-task execution. It does not claim Manager
fleet scheduling, production reliability, or live tracker operation. Hosted
The deterministic and authenticated Codex demos are locally green on the exact
candidate commits. Hosted CI, dependency-order publication, and clean tag
installation remain hard publication gates.

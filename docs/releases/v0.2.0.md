# Converge 0.2.0

Status: release candidate until hosted gates pass and the exact merge commit is tagged.

## What changed

- Added `cvg compose prepare`, `review`, `preview`, `materialize`, and `status`.
- Added `ConvergeCompositionReceipt/v1` with source, engine, review, lineage,
  TaskPlan, materialization, and task hashes.
- Made Task-Spec 3.8.0 an independently installed engine for the core task lifecycle.
- Made Seamwise 0.2.0 an independently installed engine required for decomposition.
- Made `cvg decompose --source <recipe>` a thin alias for `cvg compose prepare`.
- Made `cvg tasks plan --manifest <TaskPlan>` a thin Task-Spec delegation and
  removed the Converge-owned task planner.
- Removed the embedded Task-Spec tree from the Converge package.
- Added one universal `ConvergeCLIResult/v1` envelope for all 57 forms.
- Preserved exactly eleven Converge-owned skills and the stable public roots.

## Migration from v0.1.0

Converge v0.1.0 bundled a Task-Spec implementation and locally gated
decomposition artifacts. That tag remains immutable and is not representative
of the 0.2 composed architecture.

1. Install Task-Spec 3.8.0 independently.
2. Install Seamwise 0.2.0 independently when decomposition is required.
3. Remove consumer-local Converge copies of `skills/task-spec`.
4. Replace `cvg decompose --dir ...` with `cvg decompose --source <recipe>`.
5. Replace the legacy `cvg tasks plan --dir ...` preview with Seamwise compile
   followed by `taskspec plan --manifest seamwise/task-plan.json`.
6. Use `cvg compose materialize` to invoke `taskspec batch`; materialization
   never authorizes dispatch.
7. Update JSON consumers to read `ConvergeCLIResult/v1`.

## Compatibility

| Component | Supported release |
|---|---|
| Converge | 0.2.0 |
| Task-Spec | `>=3.8.0,<4.0.0`; release proof pins 3.8.0 |
| Seamwise | `>=0.2.0,<0.3.0`; release proof pins 0.2.0 |
| Bash | 3.2 or newer |
| Python | 3.11 or newer for Seamwise and release CI |
| Node | 22 for Cockpit and npm packaging |

## Release boundary

This release proves composed single-task execution. It does not claim Manager
fleet scheduling, production reliability, live tracker operation, or autonomous
approval of human decisions.

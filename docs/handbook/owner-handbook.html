Non-negotiables

01 · Why it's different

Five non‑negotiables

The eval decides done.

A task cannot settle until its evals exit 0. The maximal stub attack (all specs faked) lands all RED.

The referee is never a player.

cvg holds no API keys and calls no models. Engine CLIs authenticate themselves; the referee only frames, dispatches, and gates.

Cross-family when it matters.

Pass 4 adversary + Pass 8 tier-2 verify send work to a different model family, prompted to refute — including holdouts the builder never saw.

A loop with brakes.

Three-axis budgets (iterations · wall-clock · tokens) + stagnation. Only SETTLED, LOCAL_SETTLED, and NO_OP exit zero.

Evidence over memory.

Position is derived from cvg/ folders. Sessions die; disks don’t. cvg next never trusts chat scrollback.

Stand up the factory

cvg init

Creates workspace + .cvg/gate.yaml. Idempotent · CVG_INIT=OK|UNCHANGED.

cvg setup signing

Repo-private HMAC key so Task-Specs can be sealed. Never commit the key. Mode 0600 under Git-private state.

Readiness board + exact next step · SETUP=READY|INCOMPLETE.

setup tracker · setup key · setup repo · setup harness · doctor. Secrets stay out of .cvg/ — only choices are recorded.

Pass 0 · Procedure

Pass 0 · every step

Scope-check → grill → draft → gate

1 · Scope-check

Is this one idea or four platforms? Flag decomposition first. Look up facts in the repo / cvg/docs/ — never burn questions on what files know.

2 · Grill · frontier rounds

Design tree: pain · do-nothing · goal · scope · success · constraints · pre-mortem. Each round: numbered questions + recommended defaults. One reply answers the whole round (dictation-friendly).

Numbers carry provenance

Every number tagged (measured) · (estimated) · (guessed). A guess spawns an owned open question. Never invent “measured” under pressure.

2b · No-go exit

If do-nothing is fine → cvg/docs/no-go/<slug>.md (idea · date · owner · why · reopen condition) · cvg capture --no-go. Cheapest kill in the whole descent.

3 · Draft

cvg/docs/brd/<slug>.md from template. Executive summary last (≤60 words). Sign-off present as _pending_ until you flip to canonical.

4 · Gate

cvg capture --draft while writing (never authorizes handoff). You set canonical + real ISO date. cvg capture → CHECK_BRD=PASS.

Pass 1 · Falsifiable

Pass 1 · rewrite pattern

Vague → falsifiable

A requirement needs all three: measured quantity · threshold with unit · input condition. Else → owned open assumption.

Vague (fails)Falsifiable (spirit of the gate)
“Dashboard should be fast”Revenue-by-month ≤ 3s p95 over 12 months of orders
“Data reasonably fresh”Facts ≤ 15 min lag, ≥ 99% of the day
“Accurate reports”Reconciled revenue matches ledger within $0.01 / closed day
“Use DuckDB + dbt”Park as Pass 3 preference — not a requirement body line
Ids are forever

R-n requirements · W-n wishes/wonts. Never renumber casually — ADRs and evals cite them.

Priorities

Not everything is must. Use should/could/wont. Deliberate exclusions are honest.

Blocker gaps

Gate fails closed on missing/blank/sentinel resolutions (TBD, pending, open). Chase the named owner.

Pass 2 · Owner

Pass 2 · lifecycle & checklist

ADRs are immutable once accepted

Lifecycle

proposed → accepted → deprecated | superseded. Born proposed; accepted at review — never at scaffold time.

Supersede, don’t rewrite

Reality changes → scaffold-adr.sh --supersede NNNN. Bidirectional links. History stays honest.

Worthiness test

Hard to reverse · stood on downstream · could have been otherwise. Else glossary line, not a numbered ADR.

CLI

cvg structure · cvg structure --final (nothing left proposed) · CHECK_ADR=OK|FAIL|EMPTY

Accept
  • Terrain named in 0000-context
  • Brownfield was run, not summarized
  • Every ADR cites evidence + re-proof command
  • Terms in CONTEXT.md · spec_ref: R-n
Reject
  • Build/create/implement verbs in ADRs
  • Design leaking into terrain
  • Closing with records still proposed
  • Fabricating schema you didn’t observe

Pass 4 · Ops

Pass 4 · procedures & latency

Attack → dispose → sign · when review times out

ATTACK

Playbook + plans → headless adversary. Default-to-refuted. Emits stamped objection log — never edits plans. Provenance (family + input hashes) stamped by the referee.

GROUND

Where plans contradict tech-spec or ADRs. Cite both sides. No hand-waving.

SHARPEN

Every objection: FIX (revise plan in place) or ACCEPT (risk + named owner + reason). Empirical fights → throwaway prototype as evidence.

BARRIER

Present sharpened plans + dispositions. You sign explicitly. Agent must not start Pass 5 unsigned.

Timeout ops

Default 300s is often short for 11 files. Use CVG_TIMEOUT_SECS=900 or --timeout 900. Thin tree (steel-thread first). Avoid multi-adversary while debugging latency. Never use same-family Claude-on-Claude as a real barrier.

Pass 6 · opt-in · task-specs-to-issues

Register — specs ⇄ tracker board

One signed spec = one issue. depends_on → blocked-by. Repo specs remain canonical; the board is a shadow.

Only signed_off: true

Un-gated specs never hit the board. Skip and report the rest.

Idempotent upsert

Re-runs update; never duplicate. Issue-side marker is the key; tracker_ref is a convenience receipt only.

Exit Check travels

Pass 8 · Settlement

Pass 8 · settlement & verify

Scoped, ordered, policy-governed

Stage only authorized paths

From capability envelope fs.write — never git add -A (untracked files would slip past diff guards).

External writes are separate

Default deny → LOCAL_SETTLED. Push/PR require policy or --allow-external-writes. Commit, push, tracker, PR are four effects.

Receipt last

A pass receipt never attests a settlement that didn’t happen.

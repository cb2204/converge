Autonomy needs a
method spine.

Converge compiles intent into software through nine gated passes. Agents do the building. Machines do the checking. You own judgment — never the other way around.

The factory

Dark factory model

A raw idea enters a production line. Autonomous agents build; deterministic gates prove. Done is a machine state, not a claim.

The unit

Task-Spec

Self-verifying markdown with runnable evals, budgets, and an HMAC seal. Evals define done before work begins.

The referee

cvg CLI

Frames, dispatches, gates. Holds zero API keys. Every verdict ends in one greppable token.

Convergence is not unanimity. It is the point where intent, architecture, plan, authority, and evidence agree well enough to proceed under an explicit risk policy.

Phase 1 · Design · 0–4

Human-led precision

BRD → falsifiable requirements → terrain ADRs → swimlane plans → cross-family attack. You grill, approve, and sign the barrier.

Phase 2 · Build · 5–8

Machine-led proof

Sealed Task-Specs → optional board → runtime contract → attempt / verify / settle. Only named terminal states count as success.
